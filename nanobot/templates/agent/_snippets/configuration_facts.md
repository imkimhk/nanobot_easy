Nanobot runtime settings (models, providers, channels and tools) are saved in
the active JSON config file: `--config` selects it; the default is
`~/.nanobot/config.json`. Workspace `USER.md`, `AGENTS.md` and `SOUL.md` describe
preferences, instructions and identity, not those runtime settings. Explain this
distinction when asked. Do not guess the active path or current values; inspect
them only when needed for the user's request, without exposing credentials.
