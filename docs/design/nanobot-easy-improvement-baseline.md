## 다음 단계 제안

3단계의 우선 과제는 실행 상태 식별의 불일치를 해결하는 것이다. 기존 상태 기록에
프로세스 시작 시각과 로드된 소스/설정 지문을 묶고, PID·시작 시각이 다르면
활성 상태로 표시하지 않도록 하는 작은 변경부터 검토한다. 그 후 실제로 활성화된
경로에 대해 사례를 평가한다. 현재 꺼진 context selection의 회귀 통과만으로
운영 응답 품질이 개선됐다고 판단하지 않는다.

실제 모델 비교는 예산·후보 경로·격리 자료를 정한 후 별도로 실행한다.
3단계 제품 변경 및 4단계 배포는 이번 범위에 포함하지 않는다.
